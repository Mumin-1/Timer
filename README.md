# ФИО:    Бекмахмудов Муъминджон Рахмонджонович

## Приложение «Таймер»

**Суть приложения.** Мобильное приложение для проверки времени реакции человека.
Сначала на весь экран появляется красный цвет, через случайное время (2–6 секунд)
экран резко становится зелёным — пользователь должен как можно быстрее нажать на экран.
Приложение показывает время реакции в миллисекундах, оценку, лучший результат и среднее
значение за все попытки. Если нажать раньше времени (на красном) — попытка не засчитывается.
